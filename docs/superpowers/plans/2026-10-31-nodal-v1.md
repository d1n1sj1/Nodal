# Nodal v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Nodal v1: an open-source desktop circuit simulator with a fast Rust solver and one UI that switches between Engineer and Kids mode.

**Architecture:** A Rust library crate (`nodal-core`) holds the circuit model, the solver and damage detection. A thin Tauri shell exposes it to a React + TypeScript UI through commands. The UI edits a schematic, converts it to a `Circuit`, runs the solver, and draws results. Mode (engineer or kids) only changes presentation; the saved circuit file never contains it.

**Tech Stack:** Rust (stable), `serde`/`serde_json`, `faer` (sparse LU), Tauri v2, React 18, TypeScript, Vite, Vitest, a canvas-based schematic editor.

**Spec:** `docs/superpowers/specs/2026-10-31-nodal-design.md`

## Global Constraints

- Solver core in Rust; desktop shell Tauri; UI React + TypeScript. Licence: MIT or Apache-2.0 (dual `MIT OR Apache-2.0`).
- Speed target: a circuit of about 1,000 nodes runs a typical transient in under 1 second on a normal laptop.
- v1 parts: resistor, capacitor, inductor, voltage source, current source, ground, diode, LED, switch. No transistors or op-amps in v1.
- v1 analyses: DC operating point and transient. No AC, no SPICE import/export.
- One app, one engine, one file format. Mode is a per-user view setting and is never stored in the circuit file.
- Engineer mode: dark theme, standard schematic symbols, scope panel, readouts (voltage, current, time), modern look (rounded panels, sans-serif, one indigo accent, soft shadows).
- Kids mode: bright white and sky blue with coral and mint accents, no yellow backgrounds, colorful picture tiles, friendly wording. Tiles are skins: battery = voltage source, bulb = resistor with a power rating, switch = switch, buzzer = resistive load, motor = resistor and inductor in series, resistor = resistor. A part with no kids tile shows a generic tile.
- Both modes show the Nodal logo (three linked nodes in a rounded indigo-to-blue square) and the name "Nodal". Kids mode adds a small "Kids" tag. Every part shows an icon and a name in the parts list.
- Damage detection is computed from simulation results (power or current above a part's rating) after each run. Damaged parts get a warning and a red highlight. The LED is a diode with a forward-current limit (default 20 mA); a resistor defaults to 0.25 W.
- Platforms: Windows, macOS, Linux with standard installers. No auto-update in v1.
- Visual reference: `.superpowers/brainstorm/1776-1793472491/content/two-modes-v4.html` (look, layout, part palette; not a pixel spec).

## Review Focus

Inputs a person will hit that the spec does not name. Each line has a pinning test in the task shown.

1. A circuit with no ground, or a node connected to nothing: clear error, never a panic or NaN (Task 3).
2. Two voltage sources in a loop, or a source across a zero-ohm path (singular matrix): clear error naming the cause (Task 3).
3. A diode circuit where Newton iteration does not converge: returns an error after a bounded number of iterations, never loops forever (Task 5).
4. A circuit file with an unknown part kind (from a newer version): friendly load error, no crash; and in kids mode a part with no tile shows a generic tile (Tasks 2, 10).
5. Pressing Run on an empty circuit: a friendly "nothing to simulate" message, not a crash (Task 12).
